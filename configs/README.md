# Public configs

- `protocol_v2.json` is the current machine-readable public disclosure of the
  frozen experiments, statistics, checkpoint boundary, and known limitations.
- `checkpoint_reference_outputs_v1_1.json` contains fixed-input signatures used
  to verify representative v1.1.0 checkpoints.

Older release-candidate protocols remain available through the repository's
version tags instead of being kept on the current branch.
