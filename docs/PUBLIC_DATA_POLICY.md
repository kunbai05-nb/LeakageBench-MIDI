# Public data and artifact policy

## Allowed

Stable component IDs, split IDs, source-relative identifiers, one-way hashes, derived aggregate statistics, protocol configurations, random seeds, and fully synthetic manifests.

## Review before release

PDMX source IDs, LMD identifiers, and external URLs must be consistent with source licenses and necessary for reproducibility. The RC1 allowlist defaults to aggregates and code; identifiers are excluded unless separately approved.

## Forbidden

LMD/PDMX MIDI bytes, audio renders, copyrighted score content, raw archives, checkpoints, permanently closed clean-test material, credentials, server logs, and token/event sequences capable of reconstructing restricted source music.
