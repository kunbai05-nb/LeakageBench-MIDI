# LeakageBench-MIDI v1.0.0-rc2

This release standardizes the public research-software interface before the stable v1.0.0 release.

## Main changes

- Unified the public Python package under `leakagebench_midi`.
- Standardized public script names.
- Moved registries to `metadata/`.
- Organized paper evidence, tables, and figures under `reproducibility/`.
- Normalized documentation names and paths.
- Removed four development-only or redundant public files.
- Updated the Quick Start and paper-reproduction commands.
- Confirmed that all public tests pass.
- Preserved all scientific results and registered claim boundaries unchanged.

Scientific results unchanged.

## Breaking changes

The rc1 import path:

```python
leakagebench.release.public
```

is replaced by:

```python
leakagebench_midi
```

The rc1 import path:

```python
leakagebench.structural
```

is also replaced by:

```python
leakagebench_midi
```

The rc1 script paths have been replaced by the normalized script names documented in the Quick Start and reproduction instructions.
