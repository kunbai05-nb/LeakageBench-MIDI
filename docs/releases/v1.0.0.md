# LeakageBench-MIDI v1.0.0

## Overview

LeakageBench-MIDI v1.0.0 is the stable research software release for studying same-work family leakage in symbolic music generation evaluation.

## Main components

- Family-aware leakage analysis
- Reproducible benchmark pipeline
- Contamination analysis tools
- Mitigation utilities
- Public model loading interface

## Reproducibility

The release provides a frozen result registry, an auditable provenance chain, integrity verification, and scripts for reproducing the published result tables from the included public-safe artifacts.

## Public artifacts

The software is released under the MIT License. Companion model artifacts are distributed as a separate release and are not included in the software repository.

## Scientific scope

The project studies same-work family leakage in symbolic music generation evaluation. Its findings and tools are limited to the documented datasets, family definitions, protocols, and evaluation endpoints.

## Limitations

- Family identification has incomplete recall, so unknown relations may remain.
- External-cohort evidence is limited to the documented eligible cohort and does not establish universal generalization.
- Negative log-likelihood (NLL) is an evaluation endpoint, not a measure of perceptual music quality.
